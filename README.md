# Character Spacing Plugin for ONLYOFFICE

Plugin **Character Spacing** giúp điều chỉnh khoảng cách giữa các ký tự trong văn bản trên ONLYOFFICE Desktop Editors.

## Cài đặt

Bạn có thể cài đặt plugin bằng một trong hai cách dưới đây.

### Cách 1: Cài đặt thủ công vào thư mục plugin

1. Đóng ONLYOFFICE Desktop Editors nếu chương trình đang chạy.
2. Nhấn `Windows + R` để mở hộp thoại **Run**.
3. Nhập đường dẫn sau rồi nhấn **Enter**:

   ```text
   %LOCALAPPDATA%\ONLYOFFICE\DesktopEditors\data\sdkjs-plugins
   ```

4. Giải nén file `{5D5E6A53-6E66-4F0B-A2A6-5D8A9D9F8C01}.zip`.
5. Sao chép thư mục plugin sau khi giải nén vào thư mục `sdkjs-plugins` vừa mở. Kiểm tra để bảo đảm các tệp của plugin nằm đúng cấu trúc thư mục, không bị lồng thêm một cấp thư mục ngoài ý muốn.
6. Mở lại ONLYOFFICE Desktop Editors.
7. Mở tài liệu và kiểm tra plugin trong mục **Plugins (Plugin)**.

> **Lưu ý:** Nếu plugin chưa xuất hiện, hãy kiểm tra lại cấu trúc thư mục, sau đó đóng và mở lại ONLYOFFICE.

### Cách 2: Cài đặt từ giao diện ONLYOFFICE

1. Mở **ONLYOFFICE Desktop Editors**.
2. Mở tài liệu cần chỉnh sửa.
3. Chuyển đến tab **Plugins (Plugin)**.
4. Chọn chức năng **Install plugin / Cài đặt plugin** hoặc **Install from file / Cài đặt từ máy tính** (tên mục có thể khác nhau tùy phiên bản).
5. Tìm và chọn file `Character Spacing.plugin` trên máy tính.
6. Hoàn tất cài đặt theo hướng dẫn hiển thị trên màn hình.
7. Mở lại mục **Plugins** và chọn **Character Spacing** để sử dụng.

## Khắc phục sự cố

- **Không thấy plugin sau khi cài:** Khởi động lại ONLYOFFICE và kiểm tra lại thư mục cài đặt.
- **Không cài được từ file:** Kiểm tra xem file được chọn có đúng là `Character Spacing.plugin` và còn nguyên vẹn hay không.
- **Cài thủ công nhưng không hoạt động:** Kiểm tra xem thư mục plugin sau khi giải nén có chứa trực tiếp các tệp cần thiết của plugin hay không.
